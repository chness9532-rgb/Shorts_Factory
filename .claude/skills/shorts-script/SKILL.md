# 쇼츠 대본 기획 스킬 (shorts-script)

이 스킬은 `src/llm_module.py`의 `generate_shorts_source()`가 클로드에게 시키는 것과
**정확히 동일한 규격**의 결과물을 직접 만들어낸다. 목적은 사용자가 API 비용 없이
대본을 초안·수정·확정하고, 그대로 파이프라인에 흘려보낼 수 있게 하는 것.

## 입력
- **책 제목**(필수). 없으면 사용자에게 한 줄로 물어본다.
- 톤/타깃 요청이 있으면 반영(예: "더 도발적으로", "20대 대상").

## 출력 규격 (절대 규칙 — 위반 시 파이프라인이 JSON 파싱에 실패한다)
`extract_robust_json()`은 `image_prompt_1` 과 `script_1` 키가 모두 있는 객체를 찾는다.
따라서 아래 6개 키를 **정확한 이름으로** 채운 순수 JSON 하나만 만든다.

```json
{
  "script_1": "0~10초 구간 대본",
  "script_2": "10~20초 구간 대본",
  "script_3": "20~30초 구간 대본",
  "image_prompt_1": "0~10초 영문 이미지 프롬프트",
  "image_prompt_2": "10~20초 영문 이미지 프롬프트",
  "image_prompt_3": "20~30초 영문 이미지 프롬프트"
}
```

### 대본(script_1~3) 작성 규칙
- 조회수 100만짜리 책 리뷰 숏폼 톤. 확신에 찬 어조(~입니다, ~하세요, ~하죠).
- 자막 가독성을 위해 `\n`(줄바꿈)을 **자주** 넣는다. 한 줄이 너무 길면 안 됨
  (자막은 1080폭·좌우 여백 120px·폰트 56px 영역에 들어간다).
- 1구간=강력한 후킹 질문/충격, 2구간=반전/핵심, 3구간=통찰/마무리.

### 이미지 프롬프트(image_prompt_1~3) 작성 규칙 — AI 생성 실패 방지 절대 규칙
1. **인물 얼굴 정면 클로즈업 금지** (이목구비가 기괴해짐).
2. 인물 등장 시 반드시 **뒷모습(back view) / 옆모습(side profile) / 웅장한 배경 속 전신(full shot)** 구도만.
3. 대본 무드에 맞는 고급 사물(황금 모래시계, 서재, 만년필 등)이나 압도적 배경(스카이라인, 은하수) 위주.
4. 반드시 포함: `photorealistic, cinematic composition, award-winning photography, high-end grading`.
5. 이미지 안에 **글자(Text) 절대 금지**.
6. 영문으로 작성.

## 절차
1. 위 규칙대로 6개 키를 채운다.
2. 사용자에게 **한국어 대본을 사람이 읽기 좋게** 먼저 보여주고, 영문 프롬프트도 함께 제시한다.
3. 확정되면 사용자가 원할 경우 `outputs/scripts/<제목>_shorts_prompts.txt` 형식으로
   저장하거나(main.py 저장 포맷 참고), `build-short` 스킬로 넘겨 바로 영상화한다.
4. JSON을 저장/전달할 때는 순수 JSON만 — 앞뒤 인사말·마크다운 금지.

## 주의
- 실제 영상 생성(이미지·TTS·인코딩)은 하지 않는다. 그건 `build-short` 스킬 담당.
